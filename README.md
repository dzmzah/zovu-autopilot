# ZOVU autopilot

Сам пишет и публикует посты в Instagram и Facebook. Работает на серверах
GitHub — компьютер включать не нужно.

**Расписание:** 9:00 и 18:00 по Польше. На каждый слот три попытки (планировщик
GitHub задерживает и роняет запуски), повторную публикацию не даёт отметка слота
в `state.json`.

**Витрина:** [dzmzah.github.io/zovu-autopilot](https://dzmzah.github.io/zovu-autopilot)
— те же посты для ручной выкладки, а наверху плашка состояния.

---

## Как понять, что всё хорошо

Открыть витрину с телефона. Зелёная плашка «Autopilot działa» — значит пост
вышел меньше 26 часов назад. Красная — публикация встала.

О состоянии кричат три независимых канала:

| Канал | Когда | Куда |
|---|---|---|
| `straznik.yml` → `doktor.mjs` | 12:00 UTC ежедневно | красный ран → письмо на zovu.pl@gmail.com |
| Плашка на витрине | при каждом прогоне | видно с телефона |
| `straznik-glosowy.ps1` (ПК Захара, задача «ZOVU straznik glosowy») | 15:00 ежедневно | голос вслух, только если встало |

Сторож смотрит не на «зелёный ли последний ран», а на РЕЗУЛЬТАТ: вышел ли пост.
Так и надо: блокировку Meta 31.07 не замечали девять дней именно потому, что
ранны были зелёные — скрипт честно отрабатывал, просто без поста.

## Красный ран — не всегда поломка

**Сначала посмотреть первую строку лога.** Если там `(dry run)` — это ручной
тест, он ничего не публиковал и на ленту не влиял. GitHub шлёт письма и на них.

## Если публикация встала

```bash
# что именно сломалось — шесть проверок разом
gh workflow run "ZOVU strażnik" --repo dzmzah/zovu-autopilot
gh run list --repo dzmzah/zovu-autopilot --workflow "ZOVU strażnik" --limit 1
```

Сторож отвечает по-человечески: истёк ли токен, кончилась ли дневная квота
Gemini, стоит ли очередь, сколько времени прошло с последнего поста.

Дальше по симптому:

- **`Meta blokuje dostęp`** — аккаунт разработчика на проверке личности.
  Снимается только человеком: developers.facebook.com → Confirm Account.
  Важно: заходить ОДНИМ личным аккаунтом в чистой сессии, иначе чекпоинт
  падает в `Przepraszamy, wystąpił błąd`. С телефона не сделать.
  Посты в это время не теряются — встают в `pending.json` и уйдут сами.
- **`WYCZERPANY LIMIT` у Gemini** — дневная квота бесплатного тира. Подождать
  сутки; если повторяется, сократить число проверок кадров в `photo.mjs`.
- **`token Instagrama: Instagram odrzuca token`** — токен продлевается сам при
  каждой публикации, поэтому умереть может только после долгого простоя.
  Завести заново: `TOKEN_KEY=<ключ> node token-store.mjs init`.
- **`tekst nie przeszedł kontroli`** — модель четыре раза подряд написала
  запрещённый оборот и починка не справилась. Одиночный сбой; повторяется —
  смотреть стоп-лист `BANNED` в `content-engine.mjs`.

## Ручной прогон

```bash
# посмотреть пост глазами, ничего не публикуя (картинка ляжет в артефакты)
gh workflow run "ZOVU autopilot" --repo dzmzah/zovu-autopilot -f dry=true -f kind=single
gh run download <id> --repo dzmzah/zovu-autopilot -n podglad-postu -D podglad
```

`kind`: `auto` (по ротации), `single`, `carousel`, `reel`.
**Рилсы выключены из автоматической ротации** — автособранный ролик не дотягивает
до уровня, который агентство может показывать у себя. Движок жив, зовётся руками.

## Из чего собран

| Файл | Что делает |
|---|---|
| `run-once.mjs` | весь цикл: очередь → пост → публикация → состояние |
| `content-engine.mjs` | темы, форматы, промпт, вызов модели, проверка и починка текста |
| `photo.mjs` | живой кадр из Pexels под смысл поста + отсев чужих логотипов |
| `render.mjs` | HTML → Chromium → JPEG: пост, обложка, слайды, финальный CTA |
| `trends.mjs` | 14 новостных лент, сюжет берётся при подтверждении ≥3 редакциями |
| `fb-publish.mjs` | публикация на страницу Facebook (отдельный токен и правила) |
| `doktor.mjs` | сторож: жива ли система целиком |
| `gotowe.mjs` | собирает витрину с плашкой состояния |

Состояние ротации (`state.json`) и очередь (`pending.json`) коммитятся обратно
в репозиторий — иначе каждый прогон начинал бы с нуля.

## Правила, за которые заплачено

- **Тихая деградация = поломка, которую найдут через неделю.** Любой автомат,
  который «переживает» отказ, обязан о нём кричать в первый же день.
- **Отметка слота важнее поста.** Не сохранилась — следующая попытка того же
  слота выложит второй пост подряд, а это ровно та «необычная активность», за
  которую Meta закрывает доступ.
- **Живое фото вместо генерённых 3D-объектов.** Стеклянный объект на чёрном
  читается как заглушка, а агентство продаёт качество контента.
- **Затемнять кадр легче, чем кажется правильным.** Притушили «как надо» —
  съёмки не видно, то есть незачем было её брать. Контраст букв держит вуаль
  под текстом, а не заливка всего кадра.
- **Никаких выдуманных цифр** и никаких общеновостных лент: первый же прогон
  выдал «ракета упала в Польше», а пост агентства на такой теме — удар по себе.
