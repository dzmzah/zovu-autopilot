# Публикация через n8n

`zovu-publikacja.json` — воркфлоу, который принимает готовый пост от автопилота
и выкладывает его в Instagram и на страницу Facebook.

## Как включить

1. В n8n: **Workflows → Import from File** → выбрать `zovu-publikacja.json`
2. Задать два токена как переменные окружения n8n (не вписывать их в сам
   воркфлоу — файл лежит в публичном репозитории):

   ```
   INSTAGRAM_TOKEN=...
   FACEBOOK_PAGE_TOKEN=...
   ```

   Запуск с ними: `set INSTAGRAM_TOKEN=... && set FACEBOOK_PAGE_TOKEN=... && npx n8n start`

3. Нажать **Publish** в интерфейсе. Активация через REST не срабатывает — только кнопкой.
4. Скопировать адрес вебхука и положить его в секрет репозитория `N8N_WEBHOOK`.

Автопилот отправляет `POST` с телом:

```json
{ "mediaUrl": "https://...jpg", "caption": "tekst posta", "kind": "single" }
```

## Что важно понимать

**Этот воркфлоу не обходит блокировку Meta.** Ноды HTTP обращаются к Graph API
теми же токенами приложения `ZOVU Content Bot`. Пока приложение под проверкой,
n8n получит ту же ошибку `API access blocked`, что и прямой вызов из автопилота.

Смысл файла в другом: когда проверка снимется, публикация включается импортом
и одной кнопкой, без переписывания кода.

## Ограничение по хостингу

Локальный n8n живёт, только пока включён компьютер. Для работы без ПК нужен
хостинг: бесплатно это Oracle Cloud Free Tier (постоянная ARM-машина), из
платного — n8n Cloud. Пока хостинга нет, генерация постов остаётся на GitHub
Actions, а n8n отвечает только за отправку.

## Рилсы

Для видео нужно поправить два места:
- нода `Instagram: kontener` уже умеет `REELS` и `video_url`
- нода `Facebook: publikuj` — заменить `/photos` на `/videos`, а параметр `url`
  на `file_url`
