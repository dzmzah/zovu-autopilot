# Музыка для рилсов

Любой файл отсюда (`.mp3`, `.m4a`, `.aac`, `.wav`) автопилот берёт случайно и
подкладывает под рилс: обрезает по длине ролика, выравнивает громкость к
-14 LUFS и гасит хвост. Пусто — рилс уходит с тишиной, а такие Instagram
показывает заметно хуже.

Обе — **Pixabay Content License**: коммерческое использование разрешено,
указание автора не требуется. Обе выбраны БЕЗ пометки «registered with
YouTube Content ID» — такие не ловят автоматических претензий.

## Если добавляешь свои

Только лицензия, разрешающая коммерческое использование. Аккаунт агентства —
не место для чужого трека: Meta глушит звук и вешает пометку о нарушении.

- **Pixabay Music** — брать треки без иконки щита (это метка Content ID)
- **Free Music Archive** — только CC0
- **Фонотека YouTube НЕ подходит:** Google прямо пишет, что за пределами
  YouTube ничего не гарантирует

Дорожка должна быть не короче 25 секунд — рилс длится 16-18.
Громкость выкручивать не надо, код выравнивает сам.
