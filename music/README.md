# Музыка для рилсов

Всё, что лежит в этой папке (`.mp3`, `.m4a`, `.aac`, `.wav`), автопилот берёт
случайным образом и подкладывает под рилс. Пусто — рилс уходит с тишиной.

Instagram заметно хуже показывает молчащие рилсы, поэтому одну-две дорожки
сюда положить стоит.

**Только лицензия, разрешающая коммерческое использование.** Аккаунт агентства —
не место для чужого трека: Meta глушит звук и вешает пометку о нарушении.
Безопасные источники: Pixabay Music, YouTube Audio Library (раздел «без указания
авторства»), Free Music Archive (CC0 / CC-BY).

Дорожка должна быть не короче 25 секунд — рилс длится 16-18.
Громкость выкручивать не надо, код сам ставит 0.75 и гасит хвост.
