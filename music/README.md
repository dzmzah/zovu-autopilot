# Музыка для рилсов

Любой файл отсюда (`.mp3`, `.m4a`, `.aac`, `.wav`) автопилот берёт по кругу и
подкладывает под рилс: обрезает по длине ролика, выравнивает громкость к
-14 LUFS и гасит хвост. Пусто — рилс уходит с тишиной, а такие Instagram
показывает заметно хуже.

## Почему «везде одна и та же музыка» — и что с этим сделано

21.08.2026, замечание Захара. Первым делом проверил саму ротацию: по истории
`rolki/stan.json` индекс честно шёл 0, 1, 2, 3, 4, 0, 1, 2 — трек менялся
каждый ролик. Причина была не в ротации, а в двух других местах.

**Первое: пять треков одного жанра.** Скрипт `pobierz-muzyke.mjs` искал их
запросами `corporate`, `upbeat`, `inspiring`, `technology` — это четыре имени
одного и того же настроения. Ротация меняла файл, а ухо разницы не слышало.
Запросы разведены: `lofi`, `hip hop`, `cinematic`, `ambient`, `funk`, `phonk`,
`acoustic guitar`, `drum and bass`. Добавлено 10 треков, в круге стало 15 —
при одном рилсе в день трек возвращается через две недели.

**Второе: один и тот же кусок.** Сборка всегда начинала трек с первого места,
где есть звук, то есть со вступления. А вступление — самая похожая часть у
любых двух треков одного жанра. Теперь точка входа идёт по кругу
0 / 27 / 54 / 81 секунды, и один и тот же трек во второй раз звучит своей
другой частью.

Сдвиг не берётся вслепую: кусок должен целиком влезать в трек, и его средняя
громкость замеряется. Тише −34 дБ (брейк, затухание в конце) — откат к началу.
Лучше знакомое вступление, чем двадцать секунд пустоты.

## Если добавляешь свои

Только лицензия, разрешающая коммерческое использование. Аккаунт агентства —
не место для чужого трека: Meta глушит звук и вешает пометку о нарушении.

- **Pixabay Music** — брать треки без иконки щита (это метка Content ID)
- **Free Music Archive** — только CC0
- **Фонотека YouTube НЕ подходит:** Google прямо пишет, что за пределами
  YouTube ничего не гарантирует

Дорожка должна быть не короче 25 секунд — рилс длится 16-24. Громкость
выкручивать не надо, код выравнивает сам.

В `zapas/` лежит `pixabay-dark-cyberpunk.mp3` (FreeMusicLab, 123 BPM) — Захару
не зашла, в ротацию не берётся. Чтобы вернуть, просто перенести на уровень
выше. Обратный путь тот же: не нравится трек — переносим в `zapas/`.
