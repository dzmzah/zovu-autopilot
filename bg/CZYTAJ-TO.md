# Папка bg/ — библиотека фонов

Сюда кладём картинки, сгенерированные вручную (Google Flow, ChatGPT, AI Studio).
Труба сама подставит их в слайды и наложит сверху текст, лого и рамку.

## Как называть файлы

`<тег>-<номер>.jpg` — тег это тема, номер для нескольких вариантов:

```
automatyzacja-1.jpg
automatyzacja-2.jpg
automatyzacja-3.jpg
social-1.jpg
pieniadze-1.jpg
strona-1.jpg
```

В данных поста пишешь `"bg": "automatyzacja"` — движок возьмёт файл с этим тегом.
Если файлов несколько, он **чередует их между слайдами**, чтобы не повторялись.
Можно задать фон отдельно каждому пункту: `{"heading": "...", "bg": "pieniadze"}`.

Форматы: jpg, jpeg, png, webp. Размер любой — приводится к 1080×1350 автоматически.

## Что генерировать

Только **объекты и фактуру, БЕЗ текста**. Буквы рисует шаблон — генераторы ломают
польскую диакритику (ą, ę, ł, ó, ż), поэтому текст на картинке нам не нужен.

Композиция: объекты **справа**, левая часть тёмная и спокойная — там ляжет заголовок.
Тёмный, почти чёрный фон, фиолетовый студийный свет — под фирменный стиль ZOVU.

Готовые промпты — в файле `PROMPTY.md` в корне проекта.
