# Звуки движения

Отобрано из личных паков Захара (ПАК ЗВУКОВ YOEDIT, SOUND EFFECTS) —
по его словам, это его личные файлы, поэтому лежат в репозитории.

Всё подрезано с начала, выровнено к −19 LUFS и обрезано по длине: хвост
эффекта забивает голос, а в ролике эффект работает первые полсекунды.

| роль | когда играет |
|---|---|
| `przylot-*` | приход крупного предмета |
| `odlot-*` | уход предмета за край |
| `klik-*` | мелкое движение, строка формулы |
| `kasa-1` | ценник: касса на посадке цифры |
| `uderzenie-*` | удар веса под главную цифру |
| `rozped-1` | разгон перед ударом |

Синтезированные звуки остаются запасом: если папка пуста, сборка
сама рисует шум, как раньше.
